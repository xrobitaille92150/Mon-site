# Mon-site

Site web personnel de Xavier Robitaille.

## Stack

- `index.html` unique, styles inline
- Tailwind CSS via CDN
- Serveur local : `node serve.mjs` → `http://localhost:3000`
- Screenshots : `node screenshot.mjs http://localhost:3000`
